# Security and Responsible Reporting

333 Network is a public-facing project with local-first tools. Browser-local workspace status is not proof of authenticated identity, cloud synchronization, or live hosted service availability.

Please disclose potential security vulnerabilities privately to the project maintainers rather than in public issues. Do not share private data, passwords, tokens, exploit payloads, or privileged operational information in public channels.

Internal security architecture, access controls, incident procedures, and deployment configuration are intentionally excluded from public documentation.
