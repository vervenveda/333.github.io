# Contributing to 333 Network

Thank you for helping improve the public 333 Network experience. Suggestions about usability, accessibility, clarity, broken links, device compatibility, and public information are welcome.

Please keep reports focused on user-visible behavior, and avoid placing personal information, credentials, private project files, security evidence, unpublished material, or proprietary source in public issues or pull requests.

For security issues or suspected exposure of confidential material, use a private reporting channel instead of a public discussion. Contributions to internal architecture or private implementation are handled separately from this public gateway repository.

Review the public Code of Conduct, Privacy Notice, and Accessibility Statement when participating.
