Network Principles

          
Connection should remain understandable and voluntary.

        


        

          

            
Connection by Choice

            
Members decide whether to answer, join, activate media, appear in a directory, publish work, or participate in a community feed.

          


          

            
Shared Identity, Separate Control

            
HOLLO can supply a local member identity while each application keeps its own purpose, profile choices, permissions, data, and export controls.

          


          

            
Honest Infrastructure

            
Local browser tools are not represented as live carrier, hosted meeting, mail-delivery, or synchronized cloud services until those systems exist.

          

        

      

    


    

      

        

          Current build notice: HOLLO enrollment handoffs, E=Ven applications,
          KANSEE workspaces, Bazaar profiles and feeds, SIte projects with Embed Studio, and the
          Bunya registry operate locally in this browser. Verified accounts, permanent global 333
          number reservation, hosted meetings, external mail delivery, synchronized community activity,
          remote publishing, provider APIs, and cross-device continuity still require authenticated backend services.
